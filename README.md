# CarbonDashSFX

CarbonDashSFX is a sound effect player mod for Need for Speed: Carbon that plays certain sound effects that rely on engine RPM and car speed, such as (but not limited to) redline/shift warning buzzers or speed warning chimes.

---

## Build Requirements

The following dependencies are required to build:

- Microsoft Visual Studio
- BASS Audio Library

---

## External Dependencies

The project uses the following third-party library:

- BASS Audio Library

Third-party components remain subject to their respective licenses and copyrights.

---

## Configuration

Mod configuration file is located at scripts/CarbonDashSFX.ini
SFX audio files should be placed in scripts/CarbonDashSFX/
See CarbonDashSFX.ini for instructions on how to add and edit SFX, along with deeper explanation on how the mod works
